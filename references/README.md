# References

The papers, data sets and software that RideBound cites. The numbers follow the thesis bibliography of 27 November 2026
(34 items).

The six PDF files in this folder are the publishers' versions of open-access papers. They are kept unmodified, under the
Creative Commons licence printed in each of them. Six more references are open access under a Creative Commons licence
(3, 21, 22, 26, 31, 34). They are listed by DOI only until the publisher's own file is added: the copies at hand carry a
repository cover page or a download date, or the publisher's site could not be reached. Every other reference has no open
licence, or is a web page, a data set or software, and is listed by its DOI or link only.
